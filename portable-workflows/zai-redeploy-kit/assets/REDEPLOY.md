## The enforcement stack (how this repo protects itself)

Installed by `bash scripts/setup-git-hooks.sh` (idempotent — re-run after
ANY rollback or container reset; the symlinks live in `.git/hooks/` which
a rollback can silently revert):

| Hook | Fires | What it does |
|---|---|---|
| `pre-commit` (wrapper) | before every commit | Runs every `scripts/git-hooks/pre-commit-*` sub-hook: **gitleaks** secret scanning (grep fallback if gitleaks absent) |
| `post-commit` | after every commit on `main` | **Auto-push to every configured remote** + divergence protection (force-push ONLY when the remote tip is an ancestor of local HEAD) + the self-healing PAT drop-file apply |
| (checkpoint daemon) | continuous | `scripts/auto-commit-daemon.py` commits WIP continuously (quiet-window + max-age), so a sandbox rollback loses minutes, not work |

**Verify after any restore:**
```bash
bash scripts/setup-git-hooks.sh
ls -la .git/hooks/ | grep -v sample   # MUST show: pre-commit, post-commit (+ sub-hooks via wrapper)
```

A `DIVERGED` entry in `.git/auto-push.log` = the local repo fell behind
the remotes → the rollback section below.

## Container rollback / divergence recovery (the playbook)

Symptoms: local `main` sits on an old chain; `git pull --ff-only` fails;
`.git/auto-push.log` shows rejected non-fast-forward pushes; round
artifacts vanish from disk. The remotes are ALWAYS the source of truth.

```bash
# 1. Network truth first — NEVER trust local tracking refs:
git ls-remote github main && git ls-remote origin main

# 2. Preserve the local line (cheap insurance):
git branch backup-pre-reconcile-$(date +%s)

# 3. Hard-reset to the verified remote tip (the hash from ls-remote):
git reset --hard <verified-remote-tip>

# 4. RE-ARM the enforcement (the rollback may have reverted .git/hooks/):
bash scripts/setup-git-hooks.sh

# 5. Reinstall mini-service deps (their node_modules are wiped too):
cd mini-services/chat-service && bun install && cd ../..   # if present

# 6. Restart services + verify:
bash scripts/redeploy.sh
```

**What a rollback destroys:** local-only artifacts (screenshots, /tmp
rehydrations, uncommitted work older than the daemon's quiet window).
**What survives:** every commit (all remotes) + the checkpoint daemon's
continuous saves.

## The self-healing PAT (the drop-file protocol)

1. Mint a fresh fine-grained token: github.com → Settings → Developer
   settings → Fine-grained tokens → this repo → **Contents: Read+write**
2. Paste it into `upload/GITHUB-PAT.txt` (gitignored — never committed)
3. Done. The post-commit hook (every commit) and the daemon (every poll)
   validate it, re-point the remotes, and consume the drop-file.

- Health check: `bash scripts/github-pat-refresh.sh --status`
- Stale remote (e.g. after a history rewrite): `bash scripts/github-catchup.sh`
